PERSONAL PORTFOLIO WEBSITE

Files:
- index.html
- about.html
- family.html
- hobbies.html
- gallery.html
- contact.html
- style.css
- script.js

HOW TO USE:
1. Open index.html in a web browser.
2. Search all files for YOUR FULL NAME, YOUR HOMETOWN, YOUR PROGRAMME, YOUR CAREER FIELD,
   YOUR PHONE NUMBER and replace them with your own information.
3. To add a profile photo:
   - Copy your image into this folder, e.g. profile.jpg
   - In index.html, replace:
       <div class="placeholder profile-img">...</div>
     with:
       <img class="profile-img" src="profile.jpg" alt="Profile picture">
4. Add personal gallery photos in gallery.html in the same way.

JavaScript features included:
- Welcome alert
- Dark/light mode with saved preference
- Digital clock
- Show/hide information
- Contact form validation

This project contains more than the required two JavaScript features.
